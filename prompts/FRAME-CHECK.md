# Frame Check

Run this on every generated video before it is shown to anyone.

1. Record duration, resolution, and file size.
2. Pull frames at 1s, 5s, 7s, 8s, and 9.5s for a 10-second video. For another duration, use 10%, 50%, 70%, 80%, and 95%.
3. At each frame check screens, text before the ending, logos, people placement, and look.
4. At the ending check exact product name, concept line, URL spelling, URL hierarchy, and URL isolation.
5. Write one line per checked frame, then `Verified:`, `Deviations, named plainly:`, and `Hard rules held:`.
6. A take is GOOD when it has zero screens, zero logos, exact URL, and the requested look. Deviations do not make it defective; hiding them does.
