# MuseAi Looping Variant

Use this variant only when the brief asks for a seamless loop.

Keep the same scene-only rules, but replace the held-sign ending with a physical action that returns to the opening composition. The final 5% must match the first 5% in camera position, object placement, lighting, and motion direction. Do not end on a frozen sign. Exact text is omitted unless the brief explicitly allows a transient sign that can be looped without a visible jump.
