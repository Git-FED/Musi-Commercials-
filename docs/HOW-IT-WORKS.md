# How It Works

1. Fill in `templates/product-brief.md`.
2. Copy the brief into the generic template.
3. Generate scene-only; never include the concept sentence.
4. Frame-check at 1s / 5s / 7s / 8s / 9.5s, scaled when needed.
5. Write one line per frame, verified facts, named deviations, and hard rules held.
6. Redo defective takes. Keep and report takes with non-defective deviations.

A take is good when it has zero screens, zero logos, an exact URL, and the requested look.
