# Release Checklist

- [ ] Product brief is complete.
- [ ] Generation prompt is scene-only.
- [ ] No concept sentence was sent to the generator.
- [ ] Video duration, resolution, and file size recorded.
- [ ] Frames extracted at 10%, 50%, 70%, 80%, and 95%.
- [ ] Zero screens in every checked frame.
- [ ] Zero logos or watermark marks in every checked frame.
- [ ] No text before the ending.
- [ ] Final product name and concept line are exact.
- [ ] URL is exact, largest, and alone on its line.
- [ ] People appear only where the brief permits.
- [ ] Deviations are named plainly.
- [ ] Loop requirement is satisfied, if applicable.
- [ ] Final frame-check report is saved with the take.
