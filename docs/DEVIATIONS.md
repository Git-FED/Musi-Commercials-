# Deviations

A deviation is a difference between the brief and the take, said plainly. It is not automatically a defect.

Good: “The shoppers show up at the midpoint, not only in the last 25% — the no-humans-for-75% split is not strict.”

Good: “The ending is a held sign, so it does not loop back seamlessly.”

Defects are different: any screen, logo, wrong URL, text before the ending, or concept words in the generation prompt. A defective take is redone.
